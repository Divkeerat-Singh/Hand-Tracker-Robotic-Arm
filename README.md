# Hand-Tracker-Robotic-Arm
A rudimentary python project, using the webcam to track the hands movements, and move the joints of the robotic arm accordingly.
Version 1 implements basic rotation to the Shoulder, Elbow and Wrist joints of a 2D arm based on the rotation of the hand. Version 2 will aim to implement this on a 3D rendered model of an articulated robotic arm.
